# Journaling-app

## Role
Journaling Developer

## Responsibilities
- Journal editor
- Daily writing prompts
- Journal history
- Journal customization
- Optional photo and media attachments
- Journal-related UI and interactions

## Technologies
- React Native
- Expo
- TypeScript

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Start the app

```bash
npx expo start
```

Open the app using Expo Go or an Android emulator.
